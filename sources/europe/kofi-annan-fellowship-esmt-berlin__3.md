# Kofi Annan Fellowship (ESMT Berlin) — discontinuation evidence (checked 2026-06-18)

The Kofi Annan Fellowship (ESMT Berlin, in cooperation with the Kofi Annan Business Schools
Foundation, The Hague) was historically a fully-funded award (full tuition + travel/
accommodation/fees; per aggregators ~€58,000 value) for an emerging leader resident in a
UN-listed LDC/LLDC (or Palestine), for the MBA (Jan intake, deadline Sep 30) or MIM (Sep
intake, deadline Jun 30).

However, as of 2026-06-18 there is NO live OFFICIAL ESMT page for it:

1. https://esmt.berlin/degrees/kofi-annan-fellowship  -> HTTP 404 Not Found.
2. The old aggregator-cited official URL
   http://www.esmt.org/degree-programs/full-time-mba/scholarship-programs
   is dead; Scholars4Dev's listing is marked "CURRENTLY CLOSED", "Last updated: 11 Jun 2018".
3. ESMT's own site search (https://esmt.berlin/search?fulltext=kofi+annan) returns NO
   results mentioning "Kofi Annan".
4. The current official ESMT master's scholarships page
   (https://esmt.berlin/master-programs/scholarships-financing) and the current official
   Full-time MBA scholarships page
   (https://esmt.berlin/mba-programs/full-time-mba/tuition-financing/scholarships)
   list ~20 scholarships in detail and NONE is the Kofi Annan Fellowship.

All current detailed descriptions of the Kofi Annan Fellowship exist only on aggregator/
blog sites (scholars4dev.com, studyqa.com, opportunitydesk.org, scholarshipsads.com,
wemakescholars.com, o4af.com, etc.), which the data-integrity rules forbid as an
officialLink and as the sole basis for the six required fields.

CONCLUSION: No verifiable official source for a current Kofi Annan Fellowship at ESMT.
The six required fields cannot be supported from an official page, and there is no valid
officialLink. found=false (program appears discontinued / no official page).
